% Proposed Appendix C methods:
We use locally generated forecasts from the fixed principal M1 checkpoint
and the public DeepMind GraphCast checkpoints~\citep{lam2023graphcast}.
GraphCast\_small uses a $1^\circ$ grid, 13 pressure levels and mesh refinement
level 5, with ERA5 training coverage of 1979--2015; the $0.25^\circ$
checkpoint uses 37 pressure levels and mesh refinement level 6, with
training coverage of 1979--2017. M1 is the same selected correction used
in the principal evaluation. Forecasts start from two observed states
six hours apart and subsequently feed back their own predictions;
M1's recurrent state starts at zero for each forecast. Evaluation uses
40 six-hourly leads through ten days, with candidate verification times
extending through January 9, 2024.

The ENS reference is the ECMWF IFS ensemble-mean forecast distributed
through \href{https://weatherbench2.readthedocs.io/en/latest/data-guide.html}{WeatherBench2}
on its conservative $240\times121$ grid. We decode available 2023 forecasts
from the extended 2016--2024 store. Its missing Zarr metadata and coordinate
arrays were reconstructed using the complete 2018--2022 sibling store;
the interpretation was checked against 71 overlapping forecast chunks.
Absent forecast chunks remain unavailable. Store paths, reconstruction
checks and availability masks are retained with the evaluation artifacts.

All forecasts are scored against the same ERA5~\citep{hersbach2020era5}
verification fields from
\href{https://github.com/google-research/arco-era5}{ARCO ERA5}, including
documented repairs validated against the independently curated
\href{https://doi.org/10.5065/BH6N-5N20}{NSF NCAR ERA5 archive}.
Native model predictions and $0.25^\circ$ verification fields are remapped
to the common $1.5^\circ$ grid using first-order conservative spherical-cell
overlap with periodic longitude; the archived ENS fields already occupy
this grid. Spatial mean squared errors use normalized cosine-latitude
weights. For each diagnostic $d$ and lead $\ell$, let $S_{d,\ell}$ be the
candidate initializations with an available ENS forecast. We apply this
same set to every model and plot
\[
  100\,
  \frac{\sqrt{|S_{d,\ell}|^{-1}\sum_{i\in S_{d,\ell}}
                        \mathrm{MSE}_{m,i,d,\ell}}}
       {\sqrt{|S_{d,\ell}|^{-1}\sum_{i\in S_{d,\ell}}
                        \mathrm{MSE}_{\mathrm{ENS},i,d,\ell}}}.
\]
Thus squared errors are pooled before taking square roots and forming
the ratio. Matching depends only on forecast availability, with
46,930 available initialization--lead--diagnostic combinations per model
and 91--108 initializations per plotted point. These are comparisons
of the specified fixed models on the available matched samples; model
architecture, pressure levels and training coverage also differ.
