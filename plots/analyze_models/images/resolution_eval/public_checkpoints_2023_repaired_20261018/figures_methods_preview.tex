% Proposed Appendix C methods:
We generate forecasts locally from the fixed principal M1 checkpoint and
the public DeepMind GraphCast checkpoints~\citep{lam2023graphcast}.
The $1^\circ$ reference is GraphCast\_small, with 13 pressure levels and
mesh refinement level 5, trained on ERA5 for 1979--2015; the $0.25^\circ$
reference uses 37 pressure levels and mesh refinement level 6, trained for
1979--2017. Both public checkpoints include precipitation as an input and
output. M1 uses the same selected correction checkpoint as the principal
evaluation. Each forecast begins with two observed states six hours apart
and subsequently feeds back its own predictions. M1's recurrent state is
initialized to zero at each forecast start, with no observational warmup.
Network calculations use bfloat16, with float32 physical fields and state
boundaries. The comparison reflects differences in spatial resolution,
pressure levels, architecture and training coverage.

Verification uses ERA5~\citep{hersbach2020era5} from
\href{https://github.com/google-research/arco-era5}{ARCO ERA5}, with
documented source-data repairs from the independently curated
\href{https://doi.org/10.5065/BH6N-5N20}{NSF NCAR ERA5 archive} validated
against unaffected times and fields. The same verification fields are
used for all three models. Predictions at their native resolution and
verification fields at $0.25^\circ$ are mapped to a $121\times240$
latitude--longitude grid ($-90^\circ$ to $90^\circ$, $0^\circ$ to
$358.5^\circ$) using first-order conservative spherical-cell overlap,
midpoint cell boundaries clipped at the poles, and periodic longitude.
For each diagnostic and lead, squared errors receive normalized
cosine-latitude weights and are averaged across all 122 initializations
before taking the square root. Verification extends through January 9,
2024. Checkpoint checksums, initialization dates, frozen evaluator code,
normalization files and source-data repair identities accompany the results.

Pointwise uncertainty estimates reported separately use 10,000 paired,
non-wrapping moving-block bootstrap draws with five consecutive
initialization dates per block; three- and seven-start blocks provide
sensitivity checks. These intervals condition on the fixed checkpoints
and evaluation dates and do not quantify training-seed variation.
