**Acronym definitions also need a consistent first-use policy.** V3 uses **SSM** without expanding it, whereas v2 expands it in the Mamba explanation. V3 spells out root-mean-square error in the abstract but does not attach **(RMSE)**; v2 does not spell it out. **ENS** is not identified precisely in the common-grid captions. **BCG** appears in the v2 memory figure while prose says “B,C groups”; label it “number of B,C groups” or define it. Check first-use expansions for **MSE, LR, PDE, S4, F-FNO**, and v2's **MemNO** and **SOTA**. For ENS, identify the actual reference product/forecast statistic rather than guessing an expansion from the acronym.

**Distinctions to preserve while standardizing:** temporal memory (mechanism), temporal memory state m_t (complete carried state), SSM state h_t (one component), causal-convolution cache (another component), temporal context (information available from history), and physical memory kernel (a theoretical object) are not interchangeable. Likewise, exact GraphCast loss, the reset-study reconstructed loss, the archived paper-formula weighted MSE, RMSE, and city-level MAE must retain separate labels. Model output resolution and verification-grid resolution are already distinguished in the text and should remain so. Temperature in °C for city trajectories and temperature RMSE in K are not a terminology inconsistency.
