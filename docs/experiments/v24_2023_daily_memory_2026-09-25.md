# Full-year 2023 evaluation and memory controls

Submitted September 25, 2026 at the user's request. This is a new frozen
campaign; the failed September 17 campaign and its artifacts are preserved.
Submission does not imply completed evaluation results.

Every policy uses all 365 daily 00 UTC initializations in 2023 and 40 six-hour
leads. December forecasts use the available January 2024 truth. All starts
have zero initial recurrent state and use full autoregressive feedback.

| ID | Checkpoint and policy |
| --- | --- |
| M1 | Selected V24 di16 faster-Mamba SWA 500–2000, carry |
| M2 | V24 di32 joint-LR SWA 500–2000, carry |
| M3 | V24 optimizer-study di16 Mamba1 SWA 2000–8000, carry |
| M1_reset | Same checkpoint as M1, reset both SSM and convolution state every step |
| C_carry | Paper V22 di16/BCG1 carry-trained SWA 2000–8000, carry evaluation |
| C_reset | Same checkpoint as C_carry, reset every evaluation step |
| R_reset | Separately reset-trained V22 di16/BCG1 SWA 2000–8000, reset evaluation |

The V22 controls retain their native checkpoint loader, predictors and rollout
arithmetic. An explicit-date adapter supplies padded data and shared exact
GraphCast host metrics. It does not relabel V22 checkpoints as V24 or relax
the V24 checkpoint contract. This campaign calculates exact losses directly;
it does not reuse the paper's approximate RMSE-based loss reconstruction.
All shard outputs also retain variable/channel RMSE and MAE.

Arrays have no concurrency throttle. Each GPU task requests one 80GB GPU,
eight CPUs, 20 GiB CPU RAM and 62 minutes. CPU jobs request two CPUs, 4 GiB
and 15 minutes. The gate requires measured 16-start runtime with a 25% margin
to fit the allocation and peak RAM below 16.25 GiB. All policy baselines must
agree with M1 within the frozen rtol=0.001 and atol=1e-6. Failed dependencies
cancel downstream jobs rather than leaving impossible dependencies queued.

The old campaign forced `--xla_gpu_deterministic_ops=true` and completed zero
preflight starts before timeout. The successful spectral pilot 14080456 used
only `--xla_gpu_enable_triton_gemm=false`, taking 16–17 minutes for eight starts
with 7.3–7.8 GiB peak RAM. This campaign restores that setting. Archived V22
res1 runs 12530971 completed 32 starts in about 40 minutes at 11.8–12.1 GiB.
These observations motivate the allocation; the new preliminary evaluations
must verify the mixed-family campaign before production can start.

aggregation, legacy rollout semantics and memory-policy provenance; all seven
