# 为什么 rescale 和滑窗仍没有带来主要气压层改善

这里区分训练目标、评估汇总和真实逐层结果。结果没有使用动态 loss 权重重算物理 RMSE。

## 第 840 步的准确含义

在八个固定短时验证起点、12 小时预报中，相对 frozen NeuralGCM：

| 变量 | 全 37 层 RMSE 改善率 | >30 hPa 的 29 层改善率 |
| --- | ---: | ---: |
| 温度 | +2.2227% | -0.8973% |
| 位势 | +1.5129% | -4.6383% |
| 东西风 u | +5.3549% | -0.4512% |
| 南北风 v | -2.3603% | -0.3799% |
| 比湿 | -0.2046% | -0.2046% |
| 云冰 | -0.6767% | -0.5736% |
| 云液水 | -0.2796% | -0.1793% |

正值改善，负值退化。不是统计显著性结论。原模型全层平方误差中，<=30 hPa 八层对温度、位势、u 风的贡献分别为 96.9439%、99.9974%、97.5818%。因此全层汇总能掩盖其他层退化。u 风只在 1、2、3 hPa 改善，其余 34 层均退化。温度在 20/30 hPa 反而退化 7.4715%/6.3475%。不能把这称为所有高空层都改善。

## Rescale 和窗口控制没有保证什么

校准使用 train-only 的每组平均 loss，把数值尺度与指定科学优先级分开。这不是对全层评估 RMSE 的校准。物理 RMSE 必须如实保留，不能通过重加权掩盖变差。

原始高空组乘 beta=1e-5 后又进入按组校准。对于未触及校准 floor 的组，beta 在 L/mean(L) 中会抵消；最终高空权重由显式 5%/95% 先验和动态系数共同决定，不能宣称最终有效权重仍被额外压低十万倍。这是原实验目标定义，并非严格关掉高空。

第 840 步温度、位势、u/v 风和比湿的 weather 动态系数都到 0.25 下限，五者之间的相对比例不能继续调整。native 涡度/散度系数约 2.873/2.927，高空两项云水到 4，但其 loss 和梯度仍很小。小梯度组会占用均值为 1 的系数预算，不能把系数份额解释为实际优化贡献。

这一时刻全部 upper data 加权 loss 约为 0.01062，只占总训练 loss 0.33498 的约 3.17%。位势 weather/upper 加权参数梯度范数约 0.04148/0.000694，相差约 60 倍。因此当前证据不支持“高空又支配了训练梯度”的简单解释。单组梯度范数既不含梯度方向冲突，也不等于 Adam 更新贡献；需要干预对照才能确定因果。

原模型顶端巨大偏差及原生 sigma 层与 1–10 hPa 输出的外推问题在 [此前诊断](../../../diagnostic0929.md) 中已有证据。外推不是已确认的唯一原因。当前训练仍使用共享参数、K=2 和截断物理反馈梯度，调权并不保证所有气压层或五天预报改善。

## 2,000 步结论

自适应组 12 小时、>30 hPa：温度 -0.4048%、位势 -0.7524%、u -0.3673%、v -0.2344%、比湿 +0.0916%、云冰 -0.3403%、云液水 -0.1047%。按 ±0.1% 显示容差，是 6 项变差、1 项近似不变。

另 16 个固定起点的五天评估中，自适应组 >30 hPa 七项全部退化：温度 -20.6958%、位势 -22.4775%、u -7.3508%、v -5.9020%、比湿 -6.2066%、云冰 -2.5735%、云液水 -1.5863%。这些是完整有限预报的误差，不能用 smoke 通过来声称有效。

## 新的严格关层对照

用户明确要求直接关闭高空目标。独立代码在 [code/weather_only](code/weather_only/README.md)，新数据目录与已有对照隔离。

- <=30 hPa 在所有 accuracy、spectrum、bias 计算之前被切除；校准与滑窗只看到 >30 hPa 的七个变量组。
- 同时关闭覆盖全柱的 native loss，避免借该路径重新监督高空。这是关高空加关闭 native 的 data-only 对照，不能仅归因于单个开关。
- 从同一个原模型和零 residual 初始化，比较固定校准权重与滑窗调权，各 2,000 步；不能继承旧的高空修正。
- 全部 37 层继续报告，主要选择指标改为 >30 hPa 七变量物理 RMSE 比率。关掉监督不等于冻结高空状态，也不保证预报改善。
- 五项 CPU 数值检查已通过；真实模型 H200 掩膜 smoke（14891022，3 分 31 秒）与跨进程恢复 smoke（14891023，9 分 23 秒）均通过。两组各 2,000 步生产训练已提交：固定校准权重 14911322，滑窗调权 14911323；中途全变量评估采样器 14911324。本报告不预先声称新方案有效。
