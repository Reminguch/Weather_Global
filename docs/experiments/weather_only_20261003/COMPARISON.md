# 严格关闭高空目标之后的结果

两组均完成 2,000 次 optimizer update，使用相同初始化、训练起点、统计和优化器设置。新实验还关闭了 native loss，所以不能把差异仅归因于高空开关。

新旧五天评估使用相同 16 个起点，frozen baseline 的全部物理 RMSE 数组逐值完全一致，已做程序核对。下面均为最后第 2,000 步，不以选择出的 best checkpoint 替代。正数表示改善，负数表示退化。

12 小时关层滑窗组在 ±0.1% 显示容差下有 2 项改善、3 项变差、2 项近似不变。五天两组仍为 7 项全部退化。smoke 通过只证明掩膜、梯度、恢复及运行契约成立，不能证明预测有效。

本次控制器仍是 EMA 窗口 100、每 20 步 probe，系数范围 0.25–4，没有同时更换控制算法。K=2 的训练时长和物理反馈 stop-gradient 也保持原样，因此关层不解决长时训练信号问题。

全部 37 层保留在 history/results JSON 与四张图中；没有删除不利层或不利 checkpoint。关层只是监督目标为零，求解器全大气状态照常推进。
