**Proposed title: Improving Long-Horizon Forecasts with Non-Markovian Corrections to Pretrained Weather Models**

Many leading global neural weather forecasters predict the next atmospheric state from a short window of recent states, imposing a Markovian approximation in that input representation. Yet atmospheric dynamics involve unresolved scales, and coarse-graining can induce history dependence in the resolved variables. We investigate whether a learned non-Markovian correction can improve forecasts beyond this finite input history. We augment a frozen pretrained GraphCast model with an additive correction branch combining graph message passing and Mamba layers whose latent states persist across autoregressive forecast steps. Only the correction branch is trained. In experiments at 1° resolution, the resulting model reduces normalized weighted mean-squared error by 16.3% across ten-day forecasts and 23.7% at day ten, with larger relative gains at longer lead times. Separate state-reset ablations, assessed with an approximate reconstruction of the loss, compare persistent memory with inference-time resets and a correction trained and evaluated without persistent state. These controls suggest that temporal memory contributes beyond additional correction capacity. The results support history-dependent correction as a promising approach to adapting pretrained weather forecasters for improved long-range prediction.

**Positioning and evidence notes — outside the abstract**

Prepared and revised on September 18, 2026, for the assumed target of ICLR 2027, using the current `main_v2.tex` manuscript and saved evaluation artifacts. The revision follows the author's framing: the contribution under investigation is a non-Markovian correction to an existing Markovian predictor; GraphCast and Mamba instantiate that approach.

The opening uses “many leading” rather than a quantitative majority or an exhaustive performance ranking. [GenCast's Methods](https://www.nature.com/articles/s41586-024-08252-9) explicitly describe a second-order Markov approximation and acknowledge partial observation of the full atmospheric state. [Aurora's Methods](https://www.nature.com/articles/s41586-025-09005-y) explicitly map the previous and current atmospheric states to the next. A genuine counterexample is [SwinRNN/SwinVRNN, JAMES 2023](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2022MS003211), which retains hidden state across forecast steps. [DLWP-HPX, JAMES 2024](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2023MS004021) also uses recurrent GRUs, but its documented inference scheme resets their state every 24 hours.

Coarse-graining can induce non-Markovian resolved dynamics; coarse resolution alone does not prove that the particular baseline input representation is insufficient. The abstract uses this as motivation and does not claim to identify a physical memory kernel. Its forecast gains do not establish a changed error-growth exponent or scaling law. “Only the correction branch is trained” replaces unmeasured claims of efficient or lightweight training. The reported selected configuration uses stochastic weight averaging and starts each forecast with zero recurrent state.

The strongest ICLR contribution is the role of persistent temporal representations in adapting a frozen graph forecaster. The conference explicitly includes graph learning and applications to physical sciences in its [call for papers](https://iclr.cc/Conferences/2027/CallForPapers). The main review question is whether persistent memory explains gains beyond added spatial capacity and model selection. The current results provide promising development evidence; an evaluation on dates excluded from selection and exact-loss memory controls would strengthen that case.

The [Code of Ethics](https://iclr.cc/public/CodeOfEthics) calls for accurate, reproducible reporting and disclosure of limitations. The abstract specifies the resolution and headline loss metric; the sample count, evaluation year, and development-set selection are retained in these notes and belong in the experimental protocol. The abstract explicitly qualifies the separate memory ablation as using an approximate reconstruction of the loss, with details documented below and in the manuscript. The abstract does not establish a physical memory kernel, independent test-set generalization, statistical significance, or operational forecasting readiness.
